PBS job `180167943.gadi-pbs` ran a reduced-model copy of the recipe to exercise all 16 diagnostic groups. Figures 7h and 7i now save nonmonotonic row latitude as an auxiliary coordinate. Figure 7h passed with the complete model selection in PBS `180184606.gadi-pbs` (exit status 0). PBS `180184961.gadi-pbs` stopped before diagnostics: resuming from a run that had itself been resumed left metadata pointing to missing copied files. PBS `180185565.gadi-pbs` resumed from the original preprocessing output and completed the full recipe (exit status 0, 27m56s). All 16 figure groups passed, producing 39 PNG plots and 157 diagnostic NetCDF files. [Full-model Figure 7h](Fig7h_Gadi_full_models.png) and [Figure 7i](Fig7i_Gadi_full_models.png) show the corrected latitude handling.

## CMIP7 `im55` time-varying `volcello` check

The published ACCESS-ESM1-6 historical monthly files in `/g/data/im55/publications` include time-varying `volcello`. A focused 1986–1987 CMIP7 recipe run using the current PR code passed Figures 4, 6a, and 6b on Gadi `analysis3-26.08` (PBS `182713673.gadi-pbs`, exit 0). The unmodified diagnostic plots are [Figure 4](Fig4_Gadi_CMIP7_ACCESS-ESM1-6_1986-1987.png), [Figure 6a](Fig6a_Gadi_CMIP7_ACCESS-ESM1-6_1986-1987.png), and [Figure 6b](Fig6b_Gadi_CMIP7_ACCESS-ESM1-6_1986-1987.png). These show a different model and period from the documentation comparisons above, so their numerical values are not directly comparable. The long model name also overlaps the top annotations in these raw plots.

For all 240 months of 1986–2005, a section-only calculation compared the PR's product of climatological velocity and volume with the mean of monthly velocity-times-volume, holding its current grid/indexing and area formulas fixed. The Figure 4 difference was `-0.000033 Sv` (155.149515 versus 155.149482 Sv; PBS `182713624.gadi-pbs`, exit 0). At 30°S the Figure 6 **net volume transport** difference was `+0.000106 Sv` (1.050500 versus 1.050605 Sv; PBS `182713719.gadi-pbs`, exit 0). Thus monthly volume variability has a negligible effect on these two aggregate estimates for this model and period. This does not test whether density-layer membership changes month to month, so it does not validate the individual Figure 6 layer transports or heat transport.

The native model mass transport variables provide an independent warning about the cross-section geometry. A comparison using `umo` and `vmo` (PBS `182713992.gadi-pbs`, exit 0) yielded 159.53 Sv at Drake Passage and 0.885 Sv net at 30°S after converting kg/s with an *assumed* reference density of 1025 kg/m³. The corresponding PR-style estimates were 155.15 and 1.051 Sv. These are indicative comparisons, not exact volume-transport references: the density conversion and section geometry need to be reconciled. At the same array indices, the velocity and tracer-grid volume coordinates are staggered (about 37 km at Drake Passage and 74 km at 30°S in the inspected sections). The existing code combines them by index. Therefore the recipe execution is validated, while the physical accuracy of the reported volume and density-layer transports remains unresolved for ACCESS-ESM1-6. The Gadi scripts and PBS logs are under `/g/data/tm70/rb5533/ESMValTool_Russel/pr4612_1600deb/jobs/`; the CMIP7 recipe output is under `/g/data/tm70/rb5533/ESMValTool_Russel/pr4612_cmip7_4920f472/output_smoke/`.
